# scripts

- 定位：工程脚本目录。
- 边界：放置启动、评测、回归和文档检查脚本，不承载核心业务模块。
- 维护：新增脚本前先判断是否属于长期能力，避免临时脚本堆积。

## 文件清单

| 文件 | 地位 | 功能 |
| --- | --- | --- |
| `README.md` | 目录地图 | 解释当前目录下有哪些成员以及它们各自做什么。 |
| `bootstrap.sh` | 初始化脚本 | 帮助本地快速准备开发依赖。 |
| `dev.sh` | 开发脚本 | 收口常用本地开发命令。 |
| `fault_drill.sh` | 演练脚本 | 验证异常场景与恢复路径。 |
| `fractal_docs.py` | 文档守门脚本 | 批量维护目录地图和文件头部契约。 |
| `generate_evaluation_dataset.py` | 评测脚本 | 构造评分/润色评测所需的数据集。 |
| `generate_realistic_dataset.py` | 评测脚本 | 扩展更真实的评测输入样本。 |
| `run_evaluation.py` | 评测入口 | 收口评测运行和结果汇总。 |
| `run_regression.sh` | 回归脚本 | 统一触发关键回归场景。 |
| `test.sh` | 测试脚本 | 降低日常测试执行成本。 |
| `test_direct_score.py` | 专项验证 | 验证评分引擎在脚本场景下的输出。 |
