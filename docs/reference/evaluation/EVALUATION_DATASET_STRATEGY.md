# 简历评分与润色系统评测集策略

## 目标
创建 50 对 JD-Resume 测试数据，全面评估 `resume-score` 和 `resume-polish` 两个 skills 的效果。

---

## 测试维度设计

### 1. 硬性指标覆盖（硬边界测试）

#### 1.1 学历层次矩阵（10 个测试对）

| 学历 | 985 | 211 | 双非一本 | 二本 | 海外Top | 海外普通 |
|------|-----|-----|----------|------|---------|----------|
| **大厂JD** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **独角兽JD** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |
| **中型JD** | ✓ | ✓ | ✓ | ✓ | ✓ | ✓ |

**测试重点**：
- 学历评分是否正确（985=100, 211=85, 双非=70）
- 不同学历是否得到合理的建议

| **中卷度JD（产品）** | ✓ | ✓ | ✓ | ✓ | ✓ |
| **低卷度JD（运营）** | ✓ | ✓ | ✓ | ✓ | ✓ |

**测试重点**：
- 实习评分是否按公司层级正确计算
- 卷度系数是否影响实习 vs 项目的权重
- 无实习但有强项目的场景是否正确评分

#### 1.3 项目经历矩阵（10 个测试对）

## 评测指标设计

### 1. 评分准确性指标

| 指标 | 计算方式 | 目标值 |
|------|----------|--------|
| **总分 MAE** | |predicted_score - ground_truth\| / n | < 5 分 |
| **总分 RMSE** | sqrt(Σ(predicted - ground_truth)² / n) | < 7 分 |
| **级别准确率** | match_level 预测正确的比例 | > 85% |
| **硬性指标 MAE** | 硬性各维度预测误差均值 | < 10 分 |
| **软性指标 MAE** | 软性各维度预测误差均值 | < 15 分 |

### 2. 润色效果指标

| 指标 | 计算方式 | 目标值 |
|------|----------|--------|
| **评分提升** | polished_score - original_score | > 5 分 |
| **关键词覆盖率** | polished_keywords / jd_required_keywords | > 80% |
| **事实编造检测** | 编造事实的改写数量 / 总改写数 | = 0 |
| **STAR完整性** | 改写后STAR要素完整的项目比例 | > 70% |

### 3. 用户满意度指标（人工评估）

| 指标 | 评分标准 | 目标值 |
|------|----------|--------|
| **改写合理性** | 1-5分，改写是否合理有用 | > 4.0 |
| **建议可操作性** | 1-5分，建议是否具体可执行 | > 4.0 |
| **报告可读性** | 1-5分，报告是否清晰易懂 | > 4.0 |

## 实施计划

### Phase 1: 测试数据收集（Week 1-2）
1. 收集 10-15 个真实 JD（技术/产品/运营）
2. 收集/合成 50 份简历（覆盖所有测试场景）
3. 完成元数据标注

### Phase 2: 基准测试（Week 3）
1. 运行 resume-score 评测
2. 记录所有预测结果
3. 计算准确性指标

### Phase 3: 润色测试（Week 4）
1. 运行 resume-polish 评测
2. 人工检查改写质量
3. 检测是否编造事实

### Phase 4: 优化迭代（Week 5）
1. 分析失败案例
2. 优化 prompts 和评分逻辑
3. 重新测试验证
