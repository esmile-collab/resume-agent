## 常见问题

### Q1: 验收测试失败了怎么办？

A: 参考 [测试与回滚机制.md](./测试与回滚机制.md#5-问题定位流程) 进行问题定位。如果是代码问题，需要回滚后重新开发。

### Q2: 如何判断是代码问题还是测试问题？

A: 参考 [测试与回滚机制.md](./测试与回滚机制.md#5.2-问题分类) 中的问题分类表格。

### Q3: 开发 Agent 需要写什么文档？

A: 只需要代码和单元测试。产品设计文档已经存在，不需要重复编写。

### Q4: 如何申请验收？

A: 使用 [开发流程规范.md](./开发流程规范.md#4-汇报格式) 中的汇报格式提交完成报告。
