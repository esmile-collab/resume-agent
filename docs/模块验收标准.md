## Stage 1: 数据层 + 最小 CLI

### M1: SQLite + 本地文件持久化

#### 接口定义

```python
# src/db/models.py
from dataclasses import dataclass
from datetime import datetime
from typing import Optional

@dataclass
class Project:
    id: str  # 自动生成的短 ID（8 字符）
    name: str  # 项目名称
    cycle: str  # 招聘周期
    created_at: datetime
    base_resume_path: Optional[str] = None

@dataclass
class ProjectJDEntry:
    id: str
    project_id: str
    raw_content: str
    source_file: str
    created_at: datetime

# src/db/crud.py
class ProjectCRUD:
    def create(self, name: str, cycle: str = "") -> Project
    def get(self, id: str) -> Optional[Project]
    def list_all(self) -> list[Project]
    def delete(self, id: str) -> bool

class ProjectJDEntryCRUD:
    def create(self, project_id: str, content: str, source_file: str) -> ProjectJDEntry
    def get(self, id: str) -> Optional[ProjectJDEntry]
    def list_by_project(self, project_id: str) -> list[ProjectJDEntry]
```

#### 验收测试

```python
# tests/acceptance/test_m1.py
def test_create_project():
    crud = ProjectCRUD()
    project = crud.create(name="test-project", cycle="")
    assert project.id is not None  # 自动生成短 ID
    assert len(project.id) == 8     # 8 字符短 ID
    assert project.name == "test-project"

def test_create_with_cycle():
    crud = ProjectCRUD()
    project = crud.create(name="test", cycle="2024春招")
    assert project.cycle == "2024春招"

def test_create_jd_entry():
    crud = ProjectCRUD()
    project = crud.create(name="test-project", cycle="")

    jd_crud = ProjectJDEntryCRUD()
    jd_entry = jd_crud.create(
        project_id=project.id,
        content="JD content here",
        source_file="test.txt"
    )
    assert jd_entry.id is not None
```

### M1.5: 最小 CLI

#### 命令接口

```bash
resume_agent project init --name <name> [--cycle <cycle>]
resume_agent project list [--format json|table]
resume_agent project get --id <id> [--format json|table]
resume_agent project delete --id <id>
```

#### 验收标准（中文输出）

| 场景 | 命令 | 预期输出 |
|---|---|---|
| 创建项目 | `resume_agent project init --name testproject` | `✓ 项目已创建: abc12345` |
| 创建带cycle | `resume_agent project init --name testproject --cycle "2024春招"` | `✓ 项目已创建: abc12345` |
| 列出项目 | `resume_agent project list` | 表格显示所有项目（含 ID 和名称） |
| 查询项目 | `resume_agent project get --id abc12345` | 显示项目详情 |
| 删除项目 | `resume_agent project delete --id abc12345` | `✓ 项目已删除: abc12345` |
| 重复名称 | `resume_agent project init --name dupetest` (两次) | 两次创建成功，ID 不同 |
| 查询不存在 | `resume_agent project get --id nonexistent` | `✗ 项目不存在: nonexistent` |

#### 验收脚本

```bash
#!/bin/bash
# test_m1_5.sh

set -e

echo "=== M1.5 CLI 验收 ==="

# 清理环境
rm -rf .data/

echo "1. 测试创建项目..."
output=$(resume_agent project init --name testproject)
echo "$output" | grep -q "项目已创建" || exit 1
# 提取项目 ID
PROJECT_ID=$(echo "$output" | grep -oE "[a-z0-9]{8}")

echo "2. 测试列出项目..."
output=$(resume_agent project list)
echo "$output" | grep -q "testproject" || exit 1

echo "3. 测试查询项目..."
output=$(resume_agent project get --id "$PROJECT_ID")
echo "$output" | grep -q "testproject" || exit 1

echo "4. 测试 JSON 格式..."
output=$(resume_agent project list --format json)
echo "$output" | python -m json.tool >/dev/null || exit 1

echo "5. 测试删除项目..."
output=$(resume_agent project delete --id "$PROJECT_ID")
echo "$output" | grep -q "项目已删除" || exit 1

echo "6. 测试重复名称创建..."
ID1=$(resume_agent project init --name samename 2>&1 | grep -oE "[a-z0-9]{8}")
ID2=$(resume_agent project init --name samename 2>&1 | grep -oE "[a-z0-9]{8}")
[ "$ID1" != "$ID2" ] || exit 1

echo "7. 测试查询不存在..."
resume_agent project get --id nonexistent 2>&1 | grep -q "不存在" || exit 1

echo "✓ M1.5 CLI 验收通过"
```

## Stage 2: 工具 Stub + 路由骨架

### M2: 路由与状态机

#### 业务模型定义

```python
# src/models.py
from enum import Enum
from dataclasses import dataclass

class Intent(Enum):
    INGEST_JD = "ingest_jd"
    UPDATE_RESUME = "update_resume"
    ADD_INFO = "add_info"
    GENERATE = "generate"
    COMPARE = "compare"
    ABANDON = "abandon"

class TaskState(Enum):
    PENDING = "pending"
    SCORED = "scored"
    GENERATING = "generating"
    COMPLETED = "completed"
    ABANDONED = "abandoned"

@dataclass
class ScoreCard:
    score: int
    match_level: str  # "high" | "medium" | "low"
    suggestion: str

@dataclass
class RouteDecision:
    state: TaskState
    message: str
    actions: list[str]
    await_risk_ack: bool = False
    mode: Optional[str] = None
```

#### 验收测试

```python
# tests/acceptance/test_m2.py
def test_generate_high_match():
    from src.routes.router import TaskRouter
    from src.routes.intent import Intent, TaskState
    from src.models import ScoreCard

    router = TaskRouter()
    score_card = ScoreCard(score=80, match_level="high", suggestion="建议生成")
    decision = router.route(Intent.GENERATE, TaskState.SCORED, score_card)

    assert decision.state == TaskState.GENERATING
    assert decision.mode == "normal"

def test_generate_low_match():
    from src.routes.router import TaskRouter
    from src.routes.intent import Intent, TaskState
    from src.models import ScoreCard

    router = TaskRouter()
    score_card = ScoreCard(score=30, match_level="low", suggestion="风险确认")
    decision = router.route(Intent.GENERATE, TaskState.SCORED, score_card)

    assert decision.state == TaskState.SCORED
    assert decision.await_risk_ack == True
```

## 设计决策总结

| 项目 | 决策 | 说明 |
|---|---|---|
| **Project ID** | 自动短 ID | 8 字符 UUID，项目名称可重复 |
| **CLI 命令** | `resume_agent` | snake_case，Python 包命名惯例 |
| **数据目录** | `.data/` | 隐藏目录，保持项目目录整洁 |
| **输出语言** | 中文 | 更友好的用户体验 |
| **回滚方式** | 非破坏性分支回滚 | 使用 `git checkout` 创建新分支 |
