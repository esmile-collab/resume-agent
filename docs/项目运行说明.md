# 项目运行说明

## 1. 一键启动

```bash
cp .env.example .env
./start.sh
```

可选模式：

```bash
./start.sh backend
./start.sh frontend
```

## 2. 手动启动

### 2.1 后端

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e .
resume_agent init-db
resume_agent serve --reload
```

默认地址：`http://127.0.0.1:8000`

### 2.2 前端

```bash
cd frontend
npm install
npm run dev
```

默认地址：`http://127.0.0.1:5173`

如果后端不在默认地址：

```bash
export VITE_API_BASE_URL="http://127.0.0.1:8000"
```

## 3. 关键 API

### 创建会话

```bash
curl -X POST "http://127.0.0.1:8000/agent/sessions" \
  -H "Content-Type: application/json" \
  -d '{
    "project_name": "产品经理秋招资产",
    "cycle": "2026 秋招",
    "base_resume_text": "工作经历\n负责增长分析\n教育背景\n本科"
  }'
```

### 发送消息

```bash
curl -X POST "http://127.0.0.1:8000/agent/sessions/<session_id>/messages" \
  -H "Content-Type: application/json" \
  -d '{
    "role": "user",
    "content": "我想投策略产品，请帮我评分并生成简历。"
  }'
```

### 获取快照

```bash
curl "http://127.0.0.1:8000/agent/sessions/<session_id>"
```

### 查看产物

```bash
curl "http://127.0.0.1:8000/agent/projects/<project_id>/artifacts"
```

### 导出产物

```bash
curl -X POST "http://127.0.0.1:8000/agent/artifacts/<artifact_id>/export" \
  -H "Content-Type: application/json" \
  -d '{"format": "docx"}'
```

## 4. 产物目录

默认路径：`.data/artifacts/<project_id>/`

1. `jd/`：项目级 JD 文本。
2. `resume/`：基础简历文本。
3. `state/`：dialog messages / dialog summary。
4. `agent/outputs/`：评分、生成、润色与导出结果。

## 5. 常用检查

### 测试

```bash
python -m pytest tests/acceptance tests/unit/test_fractal_docs.py
```

### 前端构建

```bash
cd frontend
npm run build
```

### 文档一致性

```bash
python scripts/fractal_docs.py --check
```
