## 当前边界

- 循环由用户新消息驱动；代码当前按预定工具步骤执行。
- 评分读取基础简历 / 经历，编辑后的产物尚未自动回流重评分。
- 评分发生在生成 / 润色前。图中没有把新草稿自动接回评分器，也没有把规则润色画成自主模型反思。
- 图中的问题沉淀对应已有报告、观察、差异与版本；没有单独的问题数据库或自动学习服务。
