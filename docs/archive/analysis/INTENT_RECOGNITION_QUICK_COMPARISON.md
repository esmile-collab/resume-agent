# 意图识别方案快速对比

## 方案对比表

| 方案 | 准确率 | 成本/次 | 开发时间 | 延迟 | QPS | 推荐度 |
|------|--------|---------|----------|------|-----|--------|
| **混合策略+选择性CoT** | 90%+ | $0.00004 | 1周 | ~200ms | 无限 | ⭐⭐⭐⭐⭐ |
| 纯Query改写+CoT | 92% | $0.0005 | 3天 | ~500ms | 有限 | ⭐⭐⭐ |
| 专门小模型 | 80-90% | $0 | 4-6周 | <50ms | >1000 | ⭐⭐⭐ |

## 落地快且收益高：TOP 3

### 🥇 第1名：混合策略 + 选择性 CoT

```
收益：准确率 70% → 90%+ (+20%)
成本：$0.00004/次
开发：1 周
```

**为什么第一？**
- ✅ 落地最快（1 周）
- ✅ 收益最高（+20% 准确率）
- ✅ 成本可控（$0.00004/次）
- ✅ 可维护性强

**架构**：
```python
# 80% 规则匹配（免费）
# 15% 简单 LLM（$0.0001）
# 5% CoT（$0.0005）
# 平均成本：$0.00004/次
```

---

### 🥈 第2名：纯 CoT（适合快速验证）

```
收益：准确率 70% → 92% (+22%)
成本：$0.0005/次
开发：3 天
```

**适合场景**：
- 需要快速验证 LLM 效果
- 用户表达复杂/模糊
- 对可解释性要求高

**缺点**：
- 成本较高（比混合方案贵 12 倍）
- 延迟较高（~500ms）

---

### 🥉 第3名：专门小模型（高并发场景）

```
收益：准确率 70% → 85% (+15%)
成本：$0/次（但需 $500-2000 训练成本）
开发：4-6 周
```

**适合场景**：
- QPS > 100（强烈推荐）
- QPS > 1000（必须做）
- 对延迟敏感（<50ms）

**收益计算**：
```
假设 QPS = 1000
LLM 成本：$0.00006 × 1000 × 86400 × 365 = $1,897,920/年
小模型成本：$0 + $1000（训练） = $1000
节省：~$190 万/年 ✅
```

---

## 一句话建议

| 场景 | 推荐方案 |
|------|----------|
| **快速上线** | 混合策略 + 选择性 CoT |
| **验证效果** | 先用纯 CoT，3 天看效果 |
| **高并发（QPS>100）** | 一定要训练小模型 |
| **低并发（QPS<10）** | 混合策略就够了 |
