## 📋 润色规则总结

### ✅ 允许的操作

1. **同义词替换**：用更专业的词表达已有内容
2. **逻辑重组**：调整叙述顺序，突出重点
3. **关键词嵌入**：在已有事实基础上添加JD关键词（当该关键词是已有内容的子集或同义词时）
4. **STAR补全**：重新组织已有内容为STAR结构
5. **表达优化**：被动→主动，模糊→具体（基于已有信息）

### ❌ 禁止的操作

1. **添加新技术**：如果原简历技能部分没有该技术
2. **添加新经验**：项目、实习中没有提及的经历
3. **编造数据**：添加原简历没有的量化数据
4. **夸大成果**：改变项目或实习的基本事实

## 🎯 实施建议

### 对润色系统的改进

1. **增加识别模块**
   - 先分析简历，标记可润色的部分
   - 每个标记部分附带润色策略说明
   - 让用户确认后再执行润色

2. **严格的事实检查**
   - 润色后自动检查是否添加了新技术
   - 对比技能清单，确保新增关键词在技能中存在
   - 对比项目/实习清单，确保不添加新经验

3. **用户确认机制**
   - 展示润色前对比
   - 高亮显示所有改动
   - 让用户逐条确认

### 对评测数据集的改进

1. **使用真实脱敏简历**
   - 替换生成的简单模板
   - 确保内容丰富、真实

2. **人工标注 ground truth**
   - 标记哪些部分可以润色
   - 标记哪些内容是事实边界
   - 提供正确的润色示例

3. **多样化测试场景**
   - 不同行业、岗位
   - 不同简历风格
   - 不同问题类型

---

**总结**：一键润色的核心价值是"优化表达，而非创造事实"。必须严格遵守这个边界。
