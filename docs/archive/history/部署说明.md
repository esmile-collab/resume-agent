# 部署说明（Resume Polisher MVP）

版本：v1.0  
日期：2026-03-02

---

## 1. 本地运行

1. 安装依赖

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
```

2. 初始化数据库（首次）

```bash
python -c "from src.db.database import init_db; init_db().close()"
```

3. 启动 API（推荐）

```bash
./start.sh
```

4. 验证服务

```bash
curl http://127.0.0.1:8000/health
```

5. CLI 用法

```bash
resume_agent --help
resume_agent resume init --name "我的简历" --file tests/fixtures/resume/sample_resume_001.txt
```

---

## 2. 测试运行

执行全部验收 + 端到端测试：

```bash
pytest -v
```

仅运行 M8/M9 相关测试：

```bash
pytest tests/acceptance/test_m8_*.py tests/e2e/test_e2e_polish.py -v
```

---

## 3. Docker（可选）

当前仓库未提供正式 Dockerfile。若需要容器化，请至少包含：

1. Python 3.11+
2. 安装 `.[dev]` 依赖
3. 暴露 `8000` 端口
4. 启动命令：`python -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000`
