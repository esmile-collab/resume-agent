## 3. 数据模型定义

### 3.1 Project 表

```sql
CREATE TABLE projects (
    id TEXT PRIMARY KEY,           -- 8字符短ID
    name TEXT NOT NULL,            -- 项目名称
    cycle TEXT,                    -- 招聘周期（如"2024春招"）
    base_resume_path TEXT,         -- 基础简历路径
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

### 3.2 project_jd_entries 表

```sql
CREATE TABLE project_jd_entries (
    id TEXT PRIMARY KEY,           -- 自动生成的JD条目ID
    project_id TEXT NOT NULL,      -- 关联的项目ID
    raw_content TEXT NOT NULL,     -- JD原始内容
    source_file TEXT,              -- 来源文件名
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (project_id) REFERENCES projects(id) ON DELETE CASCADE
);
```

## 5. ID 生成规则

Project ID 使用 8 字符短 ID：

```python
import secrets
import string

def generate_short_id(length: int = 8) -> str:
    """生成短 ID"""
    alphabet = string.ascii_lowercase + string.digits
    return ''.join(secrets.choice(alphabet) for _ in range(length))
```

```python
def test_persistence():
    # 1. 创建项目
    crud = ProjectCRUD()
    project = crud.create(name="test-persistence")

    # 2. 验证数据存在
    assert crud.get(project.id) is not None

    # 3. 模拟重启（重新创建连接）
    new_crud = ProjectCRUD()  # 重新连接数据库

    # 4. 验证数据仍然存在
    assert new_crud.get(project.id) is not None
    assert new_crud.get(project.id).name == "test-persistence"
```

## 8. 风险提示

1. **SQLite 路径**: 数据文件放在 `.data/resume_agent.db`
2. **表创建**: 使用 `IF NOT EXISTS` 避免重复创建
3. **外键**: SQLite 默认不强制外键，需要执行 `PRAGMA foreign_keys = ON`
4. **事务**: 写操作使用事务，失败时回滚
