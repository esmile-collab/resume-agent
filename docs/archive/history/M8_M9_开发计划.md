## 1. 方案概述

### 1.1 产品定位

**Resume Polisher MVP** 是砍掉评分器的快速上线版本，核心聚焦：
- **局部 patch 编辑**（非完整重写）
- **版本可追溯**（resume_version 链）
- **一键润色**（AI 生成 block-level patch）
- **CLI 交互**（无 Web 界面）

### 1.2 与现有实现的关系

| 维度 | 现有 Resume Fit Agent | Resume Polisher MVP |
|---|---|---|
| 核心输出 | 完整方向简历（多份） | 局部 patch 改写 |
| 评分系统 | S100 七维评分 | 无评分器（砍掉） |
| 版本管理 | 简单版本号 | 完整 resume_version 链 |
| Patch 支持 | 无 | polish_patch 实体 |
| 数据关系 | 1 Project → N Task Card | 1 Resume → N JD Task |

### 1.3 一句话定义

`1 份简历 + N 个 JD 卡片 + 每卡可局部润色 + 可追溯版本`

### 3.3 核心服务实现

#### 3.3.1 简历结构化切块

```python
# src/services/resume_parser.py

@dataclass
class ResumeBlock:
    block_id: str
    block_type: str  # header/summary/experience/education/skills
    content: str
    metadata: dict

class ResumeParser:
    def parse(self, resume_text: str) -> dict:
        """将简历文本解析为结构化 block 列表"""
        blocks = []
        # 按 section 切分
        # 生成 block_id
        return {
            "blocks": [asdict(b) for b in blocks],
            "raw_text": resume_text
        }

    def apply_patch(self, content_json: dict, block_id: str, new_text: str) -> dict:
        """应用 patch 到指定 block"""
        for block in content_json["blocks"]:
            if block["block_id"] == block_id:
                block["content"] = new_text
                block["modified"] = True
        return content_json
```

@dataclass
class PatchCandidate:
    target_block_id: str
    old_text: str
    new_text: str

class PolishPatcher:
    def generate_patches(
        self,
        resume_blocks: list[ResumeBlock],
        jd_text: str,
        gaps: list[dict]

        """基于 JD 不足生成局部改写 patch"""
        # 1. 按 gaps 筛选可改写的 block
        # 2. 调用 LLM 生成 patch

        # 4. 返回 Top-K patch
        return patches

    def calculate_potential_score(self, patch: PatchCandidate, jd_text: str) -> float:
        """计算改写潜力分"""
        # potential_score = 0.40 * jd_gap_relevance
        #                + 0.25 * quantification_gap

### 4.2 端到端测试场景

#### 场景 1：完整润色流程

```python
# tests/e2e/test_e2e_polish.py

def test_full_polish_workflow():
    """
    1. 上传简历
    2. 创建 JD 任务
    3. 分析（优势/不足/建议）
    4. 一键润色
    5. 应用 patch
    6. 导出简历
    """
    # 1. 上传简历
    resume = resume_crud.create(user_id="test", name="测试简历")
    version1 = version_crud.create(
        resume_id=resume.id,
        content_json=parser.parse(resume_text),
        source="upload",
        parent_id=None
    )

    # 2. 创建 JD 任务
    task = task_crud.create(
        resume_id=resume.id,
        title="前端工程师",
        jd_text=jd_text
    )

    # 3. 分析
    insight = analyzer.analyze(resume_text, jd_text)
    insight_crud.create(
        jd_task_id=task.id,
        resume_version_id=version1.id,
        strengths=insight.strengths,
        gaps=insight.gaps,
        actions=insight.actions
    )
    assert len(insight.strengths) >= 3
    assert len(insight.gaps) >= 3

    # 4. 一键润色
    patches = patcher.generate_patches(
        resume_blocks=version1.content_json["blocks"],
        jd_text=jd_text,
        gaps=insight.gaps
    )
    assert len(patches) > 0

    # 5. 应用 patch
    patch = patches[0]
    patch_crud.create(
        jd_task_id=task.id,
        resume_version_id=version1.id,
        target_block_id=patch.target_block_id,
        old_text=patch.old_text,
        new_text=patch.new_text,
        reason=patch.reason,
        potential_score=patch.potential_score
    )

    # 应用到新版本
    new_content = parser.apply_patch(
        version1.content_json,
        patch.target_block_id,
        patch.new_text
    )
    version2 = version_crud.create(
        resume_id=resume.id,
        content_json=new_content,
        source="ai_patch",
        parent_id=version1.id
    )

    # 6. 验证版本链
    assert version2.version_no == 2
    assert version2.parent_version_id == version1.id

    # 7. 导出
    exported = exporter.export(version2.content_json)
    assert patch.new_text in exported
```
