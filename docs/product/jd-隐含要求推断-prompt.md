# JD 隐含要求推断 Prompt

## 任务说明

作为专业的招聘分析专家，请从给定的岗位描述（JD）中推断出**3个隐含的用人要求**。

这些要求通常不会在JD中明确写出，但面试官在筛选简历时会潜意识地考虑。

## 推断维度

### 1. 过往经历维度
**关注点**：候选人应该具备什么样的过往经历背景才能胜任这个岗位？

**推理思路**：
- 从岗位职责倒推需要什么样的前置经历
- 从技术要求推断必要的项目/实习经验
- 从业务场景分析相关的行业/产品经验

**输出格式**：
```
维度：过往经历要求
推断依据：[岗位职责X] + [技术要求Y] → 需要候选人具备...
隐含要求：具体描述
```

### 2. 能力维度深度
**关注点**：除了明确列出的技能，候选人还需要具备哪些深层能力？

**推理思路**：
- 从"协同多个团队"推断跨部门沟通能力
- 从"透过现象看本质"推断深度分析能力
- 从"定义理想态"抽象能力要求
- 从日常工作内容推断行业理解深度

**输出格式**：
```
维度：深度能力要求
推断依据：[工作场景X] + [能力要求Y] → 需要候选人具备...
隐含要求：具体描述
```

### 3. 潜在红线/风险维度
**关注点**：什么样的候选人虽然表面匹配，但实际上不适合这个岗位？

**推理思路**：
- 从岗位的核心痛点分析候选人可能失败的场景
- 从团队协作要求推断不合适的人格特质
- 从工作节奏/压力判断不适合的候选人特征
- 从业务发展阶段推断能力错配的风险

**输出格式**：
```
维度：潜在风险/红线
推断依据：[业务特点X] + [工作要求Y] → 需要避免...
隐含要求：具体描述
```

## 使用方式

在评分流程中，将此Prompt插入到**JD解析步骤**之后，在**硬性指标评分**之前执行：

1. JD解析 → 获得结构化JD信息
2. **隐含要求推断** → 获得3个隐含用人要求（本Prompt）
3. 硬性指标评分 → 基于显性+隐性要求进行评分
4. 软性指标评估 → LLM评估软性能力
5. 报告生成 → 整合显性+隐性要求，给出双视角分析

## 注意事项

1. **区分显性vs隐性**：只推断JD中**没有明确写出**的要求
2. **优先级标注**：使用HIGH/MEDIUM/LOW标注隐含要求的重要程度
3. **基于证据**：每个推断都必须有明确的"推断依据"
4. **可操作性**：隐含要求必须能够转化为具体的评估标准
