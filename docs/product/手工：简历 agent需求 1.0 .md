# 手工草稿（归档）

状态：历史草稿，已被 `MVP_PRD_Resume_Fit_Agent.md` v0.3 取代。以下内容仅保留背景，不作为当前执行逻辑。

## 背景痛点（保留）

当前大学生找实习和校招竞争激烈，海投常见问题是：
1. 用一份通用简历投多个方向，关键词与岗位要求错位。
2. 投递前缺少可执行的最后一步质检。
3. 面试复述准备不足，导致改过的内容无法稳定表达。

## 当前有效方案（以 PRD v0.3 为准）

1. 在 `Project` 下管理多方向 `Task Card`。
2. 每张卡片独立完成“评分 -> 补充 -> 生成 -> 复核”。
3. 评分用于建议，不做硬阻断；低匹配需风险确认后进入补偿模式。
4. 卡片补充信息是私有信息，不跨卡自动同步。
5. 每次生成均版本锁定，可复盘证据链。
