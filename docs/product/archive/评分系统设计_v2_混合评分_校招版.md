# 简历评分系统设计 v2 - 混合评分方案（校招版）

版本：v2.1
日期：2026-03-02
适用场景：校招/实习生
状态：混合策略（规则匹配 + LLM 灵活评分）

---

## 1. 设计目标

1. **聚焦校招场景**：针对实习生和应届毕业生的特殊需求
2. **平衡客观与主观**：规则匹配处理硬性指标，LLM 处理软性潜力
3. **潜力优先**：更关注学习能力和发展潜力，而非经验深度
4. **用户友好**：每个分数段都有改进空间，给予鼓励和方向

---

## 2. 校招 vs 社招核心差异

### 2.1 关注点对比

| 维度 | 社招 | 校招实习 |
|---|---|---|
| **核心诉求** | 即插即用，快速上手 | 潜力优先，培养价值 |
| **经验权重** | 高（3-5年+） | 低（0-2年实习） |
| **技能深度** | 专精某领域 | 基础扎实 + 学习能力 |
| **关注时间** | 过去成就 | 未来成长性 |
| **关键风险** | 技能不匹配、适应性差 | 基础薄弱、稳定性差、学习意愿低 |

### 2.2 评分策略差异

| 维度 | 社採权重 | 校招权重 | 说明 |
|---|---|---|---|
| 工作年限 | 20% | 5% | 改为"实习年限" |
| 学历层次 | 10% | 15% | 校招更看重 |
| 专业对口 | 10% | 15% | 校招新增 |
| 学习能力 | - | 25% | 校招核心 |
| 积极性 | - | 15% | 校招核心 |

### 4.3 规则打分实现

```python
def campus_rule_based_scoring(jd_params, resume_params):
    """校招规则匹配打分"""
    scores = {}
    weights = {
        "major": 0.15,
        "education_level": 0.10,
        "gpa": 0.10,
        "internship": 0.15,
        "competition": 0.10,
        "english": 0.05,
        "projects": 0.15,
        "technical_courses": 0.10,
        "github": 0.05,
        "availability": 0.05
    }

    # 专业匹配
    if jd_params["major_requirement"]["present"]:
        scores["major"] = calculate_major_match(
            jd_params["major_requirement"]["target_majors"],
            resume_params["major"]
        )

    # 学历层次
    if jd_params["education_level"]["present"]:
        scores["education_level"] = calculate_education_level_match(
            jd_params["education_level"]["value"],
            resume_params["university_tier"]
        )

    # GPA
    if jd_params["gpa_requirement"]["present"]:
        scores["gpa"] = calculate_gpa_match(
            jd_params["gpa_requirement"]["value"],
            resume_params["gpa"]
        )

    # 实习经历
    if jd_params["internship_requirement"]["present"]:
        scores["internship"] = calculate_internship_match(
            jd_params["internship_requirement"],
            resume_params["internships"]
        )

    # 竞赛获奖
    if jd_params["competition_preference"]["present"]:
        scores["competition"] = calculate_competition_match(
            jd_params["competition_preference"],
            resume_params["competitions"]
        )

    # ... 其他维度

    # 归一化
    total_weight = sum(weights[k] for k in scores)
    normalized_score = sum(
        scores[k] * weights[k] / total_weight
        for k in scores
    ) * 100

    return {
        "raw_scores": scores,
        "normalized_score": normalized_score,
        "participating_dimensions": list(scores.keys()),
        "coverage": len(scores) / 10
    }
```

## 6. 分数融合方案

### 6.1 动态权重分配（校招版）

```python
def calculate_campus_weights(jd_param_completeness):
    """
    校招场景动态权重分配

    校招 JD 参数通常较模糊，软性评分权重应更高
    """
    # 参数完整度：0.0 ~ 1.0
    # 校招规则权重：0.35 ~ 0.50（比社招低）
    rule_weight = 0.35 + (0.15 * jd_param_completeness)
    llm_weight = 1 - rule_weight  # 0.65 ~ 0.50

    return {
        "rule_weight": rule_weight,  # 0.35 ~ 0.50
        "llm_weight": llm_weight     # 0.65 ~ 0.50
    }
```

### 6.2 分数分段定义（校招友好版）

| 分数区间 | 匹配度 | 投递建议 | 鼓励语 |
|---|---|---|---|
| **90-100** | 优秀匹配 | 可以投递，建议微调优化 | 你的简历已经很优秀了 |
| **80-89** | 良好匹配 | 可以投递，建议针对性优化 | 基础扎实，优化后更强 |
| **70-79** | 较好匹配 | 建议优化后投递 | 有明显优势，补齐短板后更强 |
| **60-69** | 中等匹配 | 建议重点优化后投递 | 有潜力，认真优化后有机会 |
| **50-59** | 基础匹配 | 谨慎投递，需要较大改进 | 建议认真提升后再投递 |
| **0-49** | 匹配不足 | 不建议投递，建议重新定位 | 差距较大，建议系统学习 |

**校招特色**：
- 更强调"潜力"和"学习"
- 给予更多鼓励和方向
- 60-69 分明确说"有机会"

## 9. 完整流程

```python
async def score_campus_resume(jd_text: str, resume_text: str):
    """校招简历评分主流程"""

    # LLM 1: 参数提取 + 软性评分（合并）
    result1 = await llm_call_1(
        model="claude-3.5-sonnet",
        prompt=campus_extract_and_score_prompt,
        input={"jd": jd_text, "resume": resume_text}
    )

    jd_params = result1["jd_params"]
    resume_params = result1["resume_params"]
    soft_scores = result1["soft_scores"]

    # 规则引擎: 硬性指标打分
    rule_score = campus_rule_based_scoring(jd_params, resume_params)

    # 分数融合（校招生软性权重更高）
    weights = calculate_campus_weights(jd_params["completeness"])
    final_score = (
        rule_score["normalized_score"] * weights["rule_weight"] +
        soft_scores["overall"] * weights["llm_weight"]
    )

    # LLM 2: 综合分析报告
    report = await llm_call_2(
        model="claude-3.5-sonnet",
        prompt=generate_report_prompt,
        input={
            "jd": jd_text,
            "resume": resume_text,
            "jd_params": jd_params,
            "rule_scores": rule_score["raw_scores"],
            "soft_scores": soft_scores,
            "final_score": final_score,
            "few_shot_examples": campus_examples  # 校招场景例子
        }
    )

    return {
        "score_card": final_score,
        "rule_details": rule_score,
        "soft_details": soft_scores,
        "report": report
    }
```
