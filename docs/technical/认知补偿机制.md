## 1. 设计目标

1. **经历不够，认知来补**：允许用户通过"理解+思考"弥补"没做过"的差距
2. **诚实标注**：不虚构经历，而是通过补偿内容表达潜力
3. **用户控制权**：即使低匹配，用户仍可选择继续（带风险提示）

---

## 2. 核心思路

> **当用户经历与JD要求差距较大，但仍坚持投递时，我们不虚构经历，而是生成"补偿内容"来弥补差距。**

### 2.1 补偿 vs 虚构

| | 补偿内容 | 虚构经历 |
|---|---|---|
| **诚实性** | ✅ 诚实标注差距 | ❌ 编造不存在经历 |
| **风险** | 面试时可能被深挖 | 面试时必然穿帮 |
| **策略** | 强调学习能力和迁移能力 | 假装做过 |
| **效果** | 展示潜力，争取机会 | 诚信风险，可能被拉黑 |

### 2.2 补偿的原理

```
经历差距 = 没做过某事
认知补偿 = 理解某事 + 能快速学会 + 有相关迁移能力

示例：
JD要求：内容运营经验
用户经历：电商选品

补偿方式：
"虽然直接内容运营经验较少，但在选品工作中积累了用户理解，
这同样适用于内容策略优化。具备快速学习能力，期待深入发展。"
```

## 3. 补偿触发条件

### 3.1 自动触发

自动触发条件（MVP）：

| 条件 | 说明 |
|---|---|
| S100 < 50 且用户完成风险确认后继续生成 | 低匹配但仍要投递 |

补充说明：
1. MVP 不因单维度低分自动切补偿模式。
2. 中匹配用户若直接生成，默认走正常生成模式。

### 3.2 手动触发

用户可随时选择"使用补偿模式"，即使匹配度中等。

## 4. 补偿内容类型

### 4.1 个人陈述（Self Statement）

**位置**：添加到简历顶部（个人简介部分）

**场景**：低匹配但仍要投递

**示例**：
```
【个人陈述】

虽然我的直接内容运营经验较少，但在电商选品工作中，我通过数据分析
积累了用户偏好理解，这与内容策略优化高度相关。我具备快速学习能力，

近期完成的学习：
• XX平台《内容运营基础》课程（5小时）
• 分析10个竞品的内容策略，输出报告

我的核心优势：
• 数据分析能力：能通过数据洞察用户需求
• 评测思维：能设计内容效果评估体系
• 跨界迁移：在非相关领域快速积累经验

非常期待能在这个方向深入发展。
```

### 4.2 求职信（Cover Letter）

**位置**：单独文件

**场景**：表达热情和理解

**示例**：
```
尊敬的招聘团队：

我对贵公司的内容运营岗位非常感兴趣。虽然我的直接经历集中在电商选品，
但我在用户数据分析、效果评估方面的经验，可以快速迁移到内容策略优化。

我一直在学习内容运营领域：
- 完成了XX课程的内容策略模块
- 用ChatGPT协助完成了1周的内容A/B测试（详见附件）
- 分析了10个竞品的运营策略

我承认直接经验有差距，但我的学习能力和迁移能力可以快速弥补。
非常期待能有机会在实践中学习和成长。

此致
敬礼

[姓名]
[联系方式]
[日期]
```

### 4.3 面试自我介绍话术

**位置**：面试准备材料

**场景**：准备面试应对

**示例**：
```
Q: "为什么你的经历和内容运营不太匹配？"

A: "确实，我的直接经历是电商选品，但我认为这两个岗位的底层能力是相通的：
都需要理解用户、都需要数据驱动、都需要效果迭代。

在选品工作中，我通过数据分析积累了用户偏好理解，这同样适用于内容策略。
我也一直在学习内容运营相关知识，完成了XX课程和小项目。

我承认直接经验有差距，但我的学习能力和迁移能力可以快速弥补。
比如在上份工作中，我用3周时间从0学会了SQL并独立完成了数据分析任务。"
```

### 4.4 简历备注（Resume Note）

**位置**：添加到简历底部

**场景**：诚实标注差距

**示例**：
```
注：本简历基于现有经历优化，针对内容运营方向添加了个人陈述等内容。

面试时可能会被深问内容运营相关经验，建议提前准备：
1. 你的用户数据分析如何迁移到内容策略？
2. 你做过哪些内容相关的学习或小项目？
3. 为什么认为选品经验可以迁移到内容运营？
```

### 4.5 提升路径建议

**位置**：单独文件

**场景**：长期提升

**示例**：
```
【6个月提升路径 - 内容运营方向】

第1个月：
• [课程] 完成XX平台《内容运营基础》（10小时）
• [小项目] 分析10个竞品的内容策略，输出报告
• [阅读] 阅读《内容运营实战》

第2-3个月：
• [小项目] 用ChatGPT做1周内容A/B测试，记录数据
• [小项目] 为朋友的账号做内容优化，观察效果
• [课程] 学习《数据分析入门》（如不会SQL）

第4-6个月：
• [项目] 申请内容运营相关实习或兼职
• [项目] 运营自己的内容账号（公众号/小红书等）
• [社群] 加入内容运营交流群，学习经验
```

## 5. 补偿内容生成逻辑

### 5.1 差距分析

```python
def analyze_gap(score_card: ScoreCard, jd: str, resume: str) -> GapAnalysis:
    """分析差距维度"""
    gaps = []

    for dimension in score_card.dimensions:
        if dimension.score < dimension.max_score * 0.4:
            gaps.append({
                "dimension": dimension.name,
                "score": dimension.score,
                "max_score": dimension.max_score,
                "gap_reason": dimension.gap_analysis
            })

    return GapAnalysis(gaps=gaps)
```

### 5.3 补偿内容生成

```python
def generate_compensation_content(gap_analysis: GapAnalysis,
                                  transferable_skills: List[str],
                                  jd: str,
                                  resume: str) -> CompensationContent:
    """生成补偿内容"""

    # 1. 个人陈述
    self_statement = generate_self_statement(
        gap=gap_analysis.main_gap,
        transferable=transferable_skills,
        tone="诚恳但不失自信"
    )

    # 2. 求职信
    cover_letter = generate_cover_letter(
        gap=gap_analysis,
        enthusiasm=extract_enthusiasm(resume),
        company_name=extract_company_name(jd)
    )

    # 3. 面试话术
    interview_script = generate_interview_script(
        gap=gap_analysis,
        transferable=transferable_skills,
        past_success=extract_learning_success(resume)
    )

    # 4. 简历备注
    resume_note = generate_resume_note(
        gap=gap_analysis,
        warning_questions=predict_interview_questions(gap_analysis)
    )

    # 5. 提升路径
    improvement_path = generate_improvement_path(
        gap=gap_analysis,
        timeframe="6个月"
    )

    return CompensationContent(
        self_statement=self_statement,
        cover_letter=cover_letter,
        interview_script=interview_script,
        resume_note=resume_note,
        improvement_path=improvement_path
    )
```

## 8. 代码结构

```python
from dataclasses import dataclass
from typing import List

@dataclass
class GapAnalysis:
    main_gap: str
    gaps: List[dict]
    severity: str  # "高" | "中" | "低"

@dataclass
class CompensationContent:
    self_statement: str
    cover_letter: str
    interview_script: str
    resume_note: str
    improvement_path: str

class CompensationEngine:
    def __init__(self, llm_client):
        self.llm = llm_client

    def compensate(self, jd: str, resume: str, score_card: ScoreCard) -> CompensationContent:
        """生成补偿内容"""
        # 1. 分析差距
        gap_analysis = self._analyze_gap(score_card)

        # 2. 识别迁移能力
        transferable = self._identify_transferable_skills(resume, jd)

        # 3. 生成补偿内容
        return self._generate_compensation(
            gap_analysis, transferable, jd, resume
        )

    def _analyze_gap(self, score_card: ScoreCard) -> GapAnalysis:
        """分析差距维度"""
        gaps = []
        for dim in score_card.dimensions:
            if dim.score < dim.max_score * 0.4:
                gaps.append({
                    "name": dim.name,
                    "score": dim.score,
                    "reason": dim.gap_analysis
                })

        main_gap = gaps[0]["reason"] if gaps else "无明显差距"
        severity = "高" if len(gaps) >= 3 else "中" if len(gaps) >= 2 else "低"

        return GapAnalysis(main_gap=main_gap, gaps=gaps, severity=severity)

    def _identify_transferable_skills(self, resume: str, jd: str) -> List[str]:
        """识别可迁移能力"""
        # 使用LLM提取和匹配
        prompt = f"""
        从以下简历中提取可以迁移到JD要求的能力：

        简历：{resume}
        JD要求：{jd}

        请输出可迁移能力列表，每项格式为"简历能力 → 可用于JD要求"
        """
        response = self.llm.call(prompt)
        return parse_transferable_skills(response)

    def _generate_compensation(self, gap_analysis: GapAnalysis,
                               transferable: List[str],
                               jd: str, resume: str) -> CompensationContent:
        """生成补偿内容"""
        # 单次LLM调用生成所有补偿内容
        prompt = f"""
        你是一个专业的求职顾问。用户经历与JD有差距，需要生成补偿内容。

        差距分析：{gap_analysis.main_gap}
        可迁移能力：{transferable}

        请生成以下内容（JSON格式）：
        {{
            "self_statement": "个人陈述...",
            "cover_letter": "求职信...",
            "interview_script": "面试话术...",
            "resume_note": "简历备注...",
            "improvement_path": "提升路径..."
        }}
        """
        response = self.llm.call(prompt)
        return parse_compensation_content(response)
```
