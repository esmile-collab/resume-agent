# 腾讯 | AI应用工程师（大模型方向）

## 岗位职责
1. 负责大语言模型（LLM）在企业级应用中的落地，包括模型选型、微调、部署优化
2. 设计和实现基于 LLM 的智能应用，如智能客服、知识问答、内容生成等
3. 优化模型推理性能，降低延迟和成本，提升用户体验
4. 跟进大模型前沿技术，探索 RAG、Agent、多模态等新技术的应用

## 任职要求
### 学历要求
- 本科及以上学历，计算机、数学、人工智能等相关专业
- 985/211院校优先，海外Top100院校优先

### 技术要求
**必备技能：**
- 熟练掌握 Python，有扎实的编程基础和数据结构与算法功底
- 熟悉 PyTorch 或 TensorFlow，有深度学习项目经验
- 了解大语言模型原理（Transformer、BERT、GPT等），有相关项目经验者优先
- 熟悉常用 NLP 技术（分词、向量表示、文本分类、命名实体识别等）

**加分技能：**
- 有 LLM 微调（SFT、RLHF）经验者优先
- 熟悉 RAG（检索增强生成）技术，有向量数据库使用经验
- 了解 LangChain、LlamaIndex 等 LLM 应用框架
- 有 Prompt Engineering 经验，了解如何优化 Prompt 效果
- 熟悉模型量化和推理加速技术（如 vLLM、TensorRT-LLM）
- 了解 Agent 技术，有相关项目经验者优先

### 经验要求
- 有大厂或独角兽公司 AI 相关实习经验者优先
- 有完整项目从0到1落地经验者优先
- 有 Kaggle、ACM等竞赛获奖经历者优先

### 软性要求
- 具备良好的学习能力和技术热情，能够快速掌握新技术
- 有较强的沟通能力和团队协作精神
- 具备数据意识，能够用数据驱动的方式优化产品
- 有较强的执行力和落地能力，能够推动项目从想法到上线

## 团队介绍
我们团队负责腾讯企业级 AI 应用的研发，包括智能客服、知识管理、内容生成等多个产品。团队氛围开放，技术氛围浓厚，有机会接触到最前沿的 AI 技术和海量业务场景。
